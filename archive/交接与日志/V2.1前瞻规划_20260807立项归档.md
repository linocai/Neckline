## 一、三板块信息架构

```text
┌─ ① 选股(原今日篮子改名) ─────────────────────────┐
│ 报告五段中的 ①情绪语境 / ③今日篮子(仅 T1/T2)      │
│ / ③b 未定档披露 / ⑤新鲜度;百分制打分卡(甲案)     │
│ ⚠ ④昨日复盘节整体迁出 → 复盘板块                  │
└──────────────────────────────────────────────────┘
┌─ ② 持仓 ─────────────────────────────────────────┐
│ 延续 V2 现功能:台账/合并敞口/计划继承/盘中动态/   │
│ 提醒(零改动,仅随 IA 微调)                        │
└──────────────────────────────────────────────────┘
┌─ ③ 复盘(新建) ───────────────────────────────────┐
│ 每日:昨日篮子复盘(九项机械判+LLM 解释,自 ④ 迁入)│
│ 累计:包成绩单(按 pack_version 归因)/ 验证率分布  │
│ / 安慰剂对照 / 偏好与能力画像(自 macOS 工作台迁入)│
```

## 二、删除清单

1. **问询台整链**:`api/inquiry.py` 端点族、客户端问询台 tab 与对话工程、`_build_search_query` 问询侧、`resolve_stock_names` 若无他处消费一并核;`inquiry_log` 停写留档;`TASK_INQUIRY` 路由退役。⚠ 按 V1 退役守门体例:守门单测迁移不丢防线,历史行读侧保留与否立项时定。
2. **T3 全链**:质量线 `tier3_min` 退役、容量 `T3≤10` 退役、`score_and_tier` 两档化、T3 相关卡/复盘/展示全删;**K4-pack/K7-pack 的 `quality_lines` 需出新包版本**(纯删键,`engine_api_version` 兼容性立项时按 ③-K7 判定规则核)——⚠ 这是包文件变更,走激活流程,但**不动策略语义**(删档位不是改判据)。评价引擎单调性检验改 T1>T2。
3. **报告 ④ 节从选股板块迁出**(服务端报告结构是否保留 ④ 数据段、仅客户端迁移展示,立项时定——倾向服务端保留、客户端重排,契约改动最小)。

## 三、复盘板块(唯一的新建功能)

- **数据全部现成**:`basket_review_daily`(九项机械判)/ 评价引擎(`eval/metrics·placebo·calibration`)/ 画像两表 / 周复盘对账——V2 已建齐,v2.1 只做**呈现与出口**。
- **每日页**:昨日篮子逐篮复盘卡(机械判九项 + LLM 解释 + 验证/证伪时点回放)。
- **累计页**:包成绩单(现役 K7 的验证率/共振率/龙头命中/可交易收益 vs 随机对照,带样本量与置信度)、五维打分各维的实盘表现(为 P3-33/34/37 的回看直接供材)。
- **校准移交件**:导出 markdown/文件,内容 = 累计页全量 + 观察项清单(P3-32/33/34/37 状态)——用户带去策略台开 K7 升级战役的标准弹药。
- **周度 unit 形态(P3-42)随本版一并定案**:复盘板块需要周度校准数据,倒逼这条 V2 遗留规划项收口。

## 四、顺带收编(立项时确认)

- **成本杠杆(P3-44)**:T3 删除天然实现「T3 不出卡不烧 LLM」;每晚 LLM 调用量随篮子数上限从 17(2+5+10)降到 7(2+5)而显著下降——立项时把预算账/超时算术同步重算。
- **⑮ 遗留客户端欠账**(对拍表 §六 未尽项、per-position 静音开关等)若有残留,随前端重排顺带清。
- **P3-41(检索并发化)仍按用户裁定留观察**,不进本版(除非立项前的观察期触发重开判据)。

## 五、明确不动

纪律章程与哨兵全链、策略包机制与 K7 判据语义、选股五层引擎(④–⑨)、盘中存拍、通知三级与 kind 体系、对账引擎、Provider 自填制(单 LLM 常态)、`prompt_context`/冻结三律/诚实披露体例。

## 六、验收标准(产品级)

- 三板块 + 设置入口,问询台与 T3 在产品面零残留;
- 选股板块只出 T1/T2,每篮百分制打分 + 五维拆解可见;
- 复盘板块:昨日复盘完整迁入、包成绩单带样本量、校准移交件可导出;
- 复盘数据链(落库/归因/对照)与 V2 逐位一致——搬展示不改判定;
- 删除面守门:停写表零新增行、退役端点 404、守门单测迁移不丢防线。
