# 交接:盲选训练考官 Agent · 考卷规格书(2026-07-26,策略线主会话起草,用户逐条拍板)

> **读者**:未来独立的「考官 Agent」会话。本文件是盲选训练(历史盲测选股训练)
> 的唯一权威规格。背景:Neckline 人机协作系统,用户 = 唯一决策人,训练目标 =
> 用户的盘前选股决策点(20→3 收口能力)。第一版模拟舱(`research/drill.py`)
> 已趟坑,本规格 = 第一版经验 + 用户 2026-07-26 讨论定案的全部升级。

## 第〇原则(用户元洞察,压倒一切)

**考卷信息集 = 实盘情报包信息集,严格同构。**考卷给什么信息,用户实盘就会看
什么信息(潜移默化的注意力训练)。因此:①考卷不得提供实盘拿不到的信息;
②实盘情报包新增信息位时,考卷同步跟进;③"信息越多越好"的边界 = 实盘可得,
不是无差别堆料。

## 一、考试模式

- 时间拉回历史某真实交易日 D(记 T0)收盘后、T+1 的**盘前**;从当日**真实候选
  逻辑**取 **12 只**票匿名呈现;用户选 **4 只(3 主选 + 1 备用)**,每只强制写
  论点 + 填**最高追价上限**;按现役纪律判分;循环积累。买入成交机制见 §九
  (2026-07-26 晚用户二次拍板)。
- **取样诚实铁则**:热门行业(行业当日强度 top20%)× 事件性(大涨/放量/涨停)
  × 趋势域(close>ma20)随机抽取,seed 记录可复现;**禁止挑"有干净答案"的题**;
  红牌票照样入池(用牌本身是考题)。

## 二、考卷载体(用户拍板:HTML,弃 MD)

- **HTML 本地页面(localhost)**,真 K 线图(蜡烛 + 量柱),每票一个标签页;
  Excel 为备选方案。第一版的 markdown 表格/Unicode 走势图**废止**(用户当头
  一棒:什么都看不清)。
- 答题区**强制论点才能提交**(预注册纪律内建 UI);提交后才可判分。答题字段
  按 §九:4 只(含备用)每只 = 论点 + 最高追价上限(相对 T0 收盘的百分比,
  页面实时换算指数化点位显示)。

## 三、每票信息卡(60 日窗,用户拍板)

1. **K 线图**:60 日蜡烛 + 量柱,价格指数化(T-60 收盘=100),日期 T-59..T0。
2. **相对大盘线(RS)**:大盘归一,画个股/大盘比值线,60 日窗——"绝对价格
   会骗人,相对强度不会"。
3. **行业分歧线**:个股/所属行业指数比值线,60 日窗——龙头识别器(板块启动
   日分歧线上劈叉者为带队)。**行业用真名**(如"锂电设备"),概念板块不用
   (成分数据有洞,K2 教训)。
4. **快照数值**:量比(vol_ratio_5)、换手率、行业持续强势天数、行业强度
   排名、年线上下/距年线、距 20 日高点、连板数。
5. **K4 红黄牌**:读 DB `strategy_versions.K4.rule["k4_advisory"]` 口径,
   **不预筛、展示给考生自己用**。
6. **消息面(硬要求,用户拍板)**:
   - 个股:异动理由/重要公告,**涨停必须给异动理由**;无消息如实写"无"。
     脱敏规则:隐公司名;产品/行业词可保留;具体金额转相对规模(如"中标
     订单约合年营收三成")。
   - 行业/板块消息:同上脱敏。
   - **大盘消息:照实给**(用户 2026-07-26 拍板,接受重大事件可能暴露日期,
     靠考生自觉不查证作弊——训练骗的是自己的数据,激励自洽);日期本身仍
     不显示。
7. **龙虎榜摘要(用户点名要)**:该票 T0 及近几日是否上榜、买卖席位**类型**
   脱敏呈现(游资/机构/量化通道/普通营业部),不给具体席位名。
8. **市场语境面板**:大盘指数 60 日形态(指数化)、T0 涨跌停家数、MA20 上下。

## 四、判分(唯一事实源,禁止重写)

- **复用 `research/drill.py` 的纪律模拟器**——已与 h9 重放器/真实引擎
  452/452 逐笔对拍。现役纪律新规:T+1 开盘买入(含滑点)、-5% 止损、回落
  止盈 8%(自峰值)、非浮盈第 5 日退出、浮盈豁免时间退出至多 15 日、先止损
  后止盈保守顺序、跌停卖不出顺延。
- 判分入口前加**成交判定薄层**(§九):先按竞价规则定"买没买进 + 买入价",
  `_sim_one` 本体零改动。
- **三重对照必报**:考生实际成交组合均值 vs 全池 12 只均值 vs 随机选 3 的

  开盘价买入"口径。另报**区间贡献诊断**:同样的主选三只若无上限限制的成绩,
  把"选股贡献"与"挂单上限贡献"拆开看。

## 五、防自欺铁则(第一版血泪,逐条继承)

1. 答案密封:key 文件与呈现件分离,判分前任何人(含考官 agent 自己的呈现
   流程)不得读 key。
2. 泄漏自检:呈现件 grep 不到真代码/6 位数字/公司名/真日期(大盘消息按用户
   拍板豁免事件性日期泄漏,**个股身份仍零泄漏**)。
3. 判分口径不得另立(见 §四)。
4. 单期结果不作结论,10-20 期才谈统计;判分反馈**盯过程不盯结果**。

## 九、买入成交机制(2026-07-26 晚,用户二次拍板:12 选 4 + 竞价挂单)

背景:第一版默认"选了就按 T+1 开盘价买进",没模拟"买不买得进去"。用户指出
实盘是盘前看、挂单买,一字板/高开追不上是真实约束,考卷必须同构(第〇原则)。

1. **决策时点**:T0 收盘后、T+1 盘前。考卷信息全部 ≤T0(不变)。
2. **答题字段**:12 只里选 4 只 = 主选 3 + 备用 1,**每只**(含备用)强制
   论点 + **最高追价上限**(相对 T0 收盘的百分比;用户拍板"低开照买",
   故区间下沿不设,退化为单一上限)。
3. **成交判定 = 竞价定胜负**(用户拍板,弃"全日限价单"方案——EOD 数据
   无法还原盘中路径,且备用票要等收盘才知道是否顶上,时序会乱):
   - T+1 开盘价 ≤ 上限(含边界)→ **按开盘价成交**(竞价单一价,无滑点;
     与第一期"开盘价×(1+滑点)"口径不同,ledger 加 `mode` 字段区分,
     跨模式不直接比均值);
   - 开盘价 > 上限 → 该票本期作废,不做盘中追补;
   - 低开(含大幅低开)→ 照买,更便宜是真实账单,-5% 止损自会结账;
   - 次日一字板/停牌 → 照旧买不进(既有 `fwd_buyable` 硬判,挂到涨停价
     也排不上队)。
4. **备用票顶替**:主选三只中**至少一只**未成交 → 备用票按它自己的上限
   同规则判定,顶一个名额;主选全成 → 备用作废;主选挂两只以上也只有
   一张备用票。四只全未成交 → **空手期**,合法入账(弱势日空手可能是赢)。
5. **判分**:成交判定层在前,`h9._sim_one`(退出模拟)零改动;基线
   (池均/随机 3)一律按"无条件开盘价买入"口径;另报区间贡献诊断
   (主选三只无上限反事实成绩)。
6. **同构提醒**:实盘决策日志同步开始记挂单上限,考卷与实盘互相校准。
