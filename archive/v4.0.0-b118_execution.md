## 1. 根因与修复

- B117 上线后，Claude 完整连通（10:50:38 登录 303 → 10:50:39 `/token` 200 → 之后 `/mcp` 全部 200）。ChatGPT 仍是登录 303 后 1 秒又一次 `POST /login`（400，请求已用过），没有 `/token`。
- 根因：Chrome 把 CSP `form-action` 用在表单提交后的整条重定向链上。B117 放行了三个回调域名，Claude 的回调不再跳转所以通过；ChatGPT 的回调页还会继续跳转，整条链仍被拦下。KX 用的是同样的 `form-action 'self'`，无可借鉴。
- 修复：`/login` 不设 `form-action`（页面只有我们自己的一个表单、内容全部转义）；其他 MCP 路由仍是 `form-action 'self'`。`default-src 'none'`、`frame-ancestors 'none'` 等其余策略不变。
