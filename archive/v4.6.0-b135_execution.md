# Neckline 4.6.0 (B135) 执行记录 — Q 期货板块上线

> 状态：**已上线**（2026-11-22 19:58 CST，代码提交 `e417b0a`，tag `v4.6.0-b135`，库结构 v10；macOS 4.6.0 (135) 已 `ditto` 覆盖安装至 `/Applications/Neckline.app`，iPhone 4.6.0 (135) Release 构建签名通过待用户用 Xcode 安装）。

## 1. 背景与用户裁定（2026-11-22）

- `Qihuo`（HZ 云）已于同日上线 V2 只读导出（`0.2.0` build 13，`schema_version: 3`，启用 5 个化工品种、11 个停用品种历史留存，`qihuo.linotsai.top` 站点停用），仅经 `https://linotsai.top/qihuo/read/<独立访问码>` 输出 JSON 数据包。
- 本次以 **Neckline 4.6.0 (B135)** 将期货板块（Q）收进 Neckline（NB 后端 + iOS/macOS Swift 双端 + 现有只读 MCP + Gemini 只读网页兜底），遵循跨项目边界：只改 `Neckline` 仓库，不改 `Qihuo`、`KXMarketTool` 与 `whynotme`。
- 用户拍板的五项关键决定：
  1. **版本号**：`Neckline 4.6.0`（B135）。
  2. **卡片默认展开策略（方案 A）**：首屏默认展开第 1 张（烧碱 `SH`），其余 4 张（`L`、`MA`、`pp`、`eg`）收起；顶栏提供「全部展开 / 全部收起」与手动刷新。
  3. **完全静默零推送**：Q 期货绝不调用 APNs，不向 iPhone 或 Mac 发任何推送通知，仅作客观记录。
  4. **开放式研究提示词**：面向 Gemini 手机端等对话 Agent 时，提示词与工具说明明确标注 Neckline 仅作为快速基线，鼓励 Agent 自由发挥自身实时搜索与研究能力，绝不限定「只能从看板取值」。
  5. **只读网页兜底与密钥同步**：启用 `/read/<访问码>/qihuo`（含单品种 `/qihuo/<代码>` 与 `?format=json`），复用 `NECKLINE_READ_KEY` 并强制 `Cache-Control: no-store`、`X-Robots-Tag: noindex, nofollow`、`Referrer-Policy: no-referrer`；`QIHUO_READ_KEY` 直接由 HZ Nginx snippet 同步至 NB `/opt/neckline/.env`（不进 Git、日志与回复）。
