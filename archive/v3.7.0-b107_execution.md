# Neckline 3.7.0 Build107（B107）执行记录

## 1. 范围与根因

本次快修针对 2026-10-11 晚报任务 `task_194cafa3c466bd115642eda7105aae55`。B106 已经把标题审计批量落库并完成了 9,783 个选中引用的持久化；续跑在目录条目补正文时，冻结输入中已经存在同一正文版本，补证路径又把该版本追加一次。发现层的 `deduplicate_documents()` 将这两个相同 `documentId/revision` 视为输入完整性错误，抛出 `ValueError`，使一个局部重复引用把整份报告终止在 `deep_read`，未进入排序和发布。

复现证据：正文集合为 21,688 条、唯一引用 21,687 条；重复引用为 `doc_00324d0a90edb098e85f36ebf3d3097c@2`。两条记录分别来自冻结输入和目录到正文的补证路径，正文内容和身份相同；目录到正文的 companion 关系仍然需要保留。

## 2. 实施

- `Backend/neckline/k10/pipeline.py` 的 `_b92_selected_body_documents()` 改为按 `EvidenceRef` 幂等收集正文；冻结输入已含正文时不重复追加，同时保留目录→正文 companion 绑定。
- `Backend/tests/test_v306_title_triage.py` 增加冻结输入已含正文版本、补证再次命中同版本的回归，断言正文只出现一次、绑定和缺口信息不丢失。
- 对外版本保持 3.7.0，Build 升至 107；同步 App 图标、API release set 与发布记录。
