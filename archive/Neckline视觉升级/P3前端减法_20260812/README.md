## 一、这些文件是什么

`P3 前端减法.dc.html` 是**设计参考**，不是可以搬进工程的代码。它用 HTML 画出「减法后应该长什么样」，
供你在**现有 SwiftUI 工程**里按既有模式重建 —— 不是把 HTML 塞进 WebView，也不是照抄 inline style。

- 目标环境：`client/Neckline/`（SwiftUI，iOS + macOS 双端，最低支持见 `project.yml`）
- 用浏览器直接打开 `.dc.html` 即可，同目录的 `support.js` 与 `ios-frame.jsx` 是运行时和 iPhone 外框，**别删**
- 保真度：**高保真（hifi）**。色 / 字阶 / 间距 / 圆角全部取自 `Components/DesignTokens.swift` 的现役令牌
  —— ⛔ **一个色令牌都不许新增**，⛔ 不许写裸 `.system(size:)`，一律走 `NKFont` 八档

文件里左边一列是**现状**（照当前 Swift 源码重建，用来核对你有没有改错对象），右边一列是**减法后**。
六组：A 选股首页 / B 篮子卡 / C 竞价 / D 持仓与离场参考 / E 数据新鲜度 / F macOS 选股板块。

- 读数行：`.5px` 上分隔线，三格等分，格内名 `10.5 / textTertiary`、值 `17/600 monospacedDigit`
  - 入场区间（textPrimary）· 失效位（`NK.down`）· 现价（textPrimary）

### C · 竞价（P3.5）

**收起态只显示**：日期 · 确认／中性／否决数量 · 关键数据质量 · 是否存在失效警报。
（= A 屏那一行；`corrupt` 与 `nil` 两态的现有分支不动）

**打开后默认先给逐篮结论**，每篮一张卡：

- 篮子名 `16/600` + 右端 verdict 徽标（`confirm` 绿实心 / `neutral` 灰 / `veto` 红 / `pending_explanation` 琥珀）
- 一条理由 `12.5 / textSecondary`
- `.5px` 分隔线下：`critical` / `context` 两个质量读数各自标色 + 右端「未触发 D0 失效」或红字「N 只触发 D0 失效位」
- 触发失效的那一篮整圈 `1px rgba(229,68,59,.35)` 描边

**折叠两组，内容一字不少**：

- 「市场背景」= 指数竞价 · 主线概览 · 竞价强势股 24 只 · 代理样本说明 · 「市场锚点只解释资金方向，不取得交易资格」
- 「数据审计」= 覆盖率 · 冻结时刻 · 缺失清单 · 跨源冲突恒空口径 · 全部逐票指标 · 历史统计

⚠ 块名与块序（1 数据状态 / 2 市场与主线概览 / 3 篮子与逐票结论 / 4 异常与风险 / 5 APP 人工观察小纸条）
是审计锚，**在展开层里原样保留**；变的只是默认先展示第 3 块。

### D · 持仓语义（P3.1 / P3.2）

现役章程 `v2.3-k8`：`loss_warning_pct=0.05` · `loss_warning_action=review` ·
`take_profit_retrace=None` · `max_hold_days=None`。

**文案表**（由**生成时**的章程配置派生，⛔ 不做全局硬替换）：

| 位置 | 现状 | 减法后（v2.3-k8） |
|---|---|---|
| 破线横幅标题 | 已破止损线 ¥30.21 | **已触及亏损警戒线 ¥30.21** |
| 横幅正文 | 低于现役章程 -5% 止损位 0.89%。系统只提醒… | 低于现役章程 -5% 警戒位 0.89%。**触发后由你复核原判断** —— 系统只提醒，不代下单、不硬拦。 |
| 刻度尺标记 | 止损 30.21 | **警戒线 30.21** |
| 四格第一格 | 距止损 | **距警戒线** |
| 四格第三格 | 回落止盈 8% | **本版无机械回落止盈** |
| 四格第四格 | 占总仓 15.9% | 删（总仓分母未下发，写死就是造第二份事实源）→ 改 **持有 D2** |
| 时间退出 | —— | **本版无机械时间退出 —— D 计数只作记录** |
| 离场参考披露 | 离场参考…不是止盈线 —— 纪律仍是回落止盈 | **离场参考是计划参考，不是止盈信号 —— 是否离场由你判断。** |

**⛔ 当前 K8 路径里禁止出现**：
「回落止盈才是纪律」「回落止盈独立生效」「时间退出照旧跑」「达到参考区间后由回落止盈接管」
以及「止损线 / 强制止损」措辞。守门单测按字面量全客户端出现次数锁死。

**历史章程回放不受影响**：一张 2026-05 的 `v1.3.3` 报告仍然显示「回落止盈 8%」「时间退出 D5」——
那是它当时的真实规则。参考文件里的 `charter` 开关就是在演示这两态。

**P3.2 推送**：不新增推送种类。内部旧 key `take_profit` 保留作兼容，对外统一显示

- 名称：**离场参考提醒**
- 正文：**现价已触达你计划中的离场参考区间；这不是止盈信号，是否离场由你判断。**

机械回落止盈**只在历史／旧章程实际配置了 `take_profit_retrace` 时**才显示。
per-position 开关文案改「触达离场参考时提醒我 / 推送名称『离场参考提醒』· 只影响这一票」。

### E · 数据新鲜度（P3.3 末条）

这一段**仍然恒在**（在 `degraded` 分支之外），只是不再恒占一屏。三态**不合并**：

| 条件 | 表现 |
|---|---|
| 三张表都当日 | 工具栏绿徽标「数据齐」，点开是完整 ⑤ 段 |
| 有落后项 | 工具栏琥珀徽标「数据 N」+ 首页顶部一条琥珀块说清后果（「今日篮子若为空，可能是**没看**而不是**今天真没有**」）+ 「看完整 ⑤ 段 ›」 |
| `dataFreshness == nil` | 灰徽标「没查到」+ 那句「⛔ 这不等于『数据新鲜』」 |

徽标规格：胶囊 `999`（这是工具栏元素，不是 `NKChip`）、5pt 状态点 + `NKFont.caption` 600、
底色取 tone 的 `.10–.14`。

### F · macOS 选股板块（P3.3 / P3.6）

骨架不变：`NKSplitLayout` 列表栏 **376 固定** + 详情栏自适应，两栏底色仍是 `listBg` / `pageBg`。

- **列表栏**：标题 → 竞价一行 → 市场状态一行 → T1 分组 + 篮子行 + 成员行 → T2 → 一行统计入口 → 盘中提示。
  「今日概览」与「昨日回执」两行从列表栏撤下。
- **成员行右端**由 RS 名次换成**入场区间**（参考文件的 `memberTail` 开关可现场对比两种）。
- **详情栏默认 = T1 第一篮的篮子卡**，不再是「今日概览」三张卡。没有篮子时才回退到概览。
- 1024 与 1440 两个宽度都不许截断。

**P3.6 加载边界** —— 把全局 `refresh()` 拆成四个：

```
refreshSelection()  → report / regime / auction
refreshPositions()  → positions / board / 持仓事件
refreshReview()     → 当前选中的 review page
refreshSettings()   → settings / provider / push kinds
```

要求：首次进入 Tab 时加载；工具栏刷新只刷新当前 Tab；深链打开某个篮子／持仓时自动补拉依赖；
保持已有的 empty / loading / error / degraded 三态。选股页移除持仓入口后，⛔ 不再每次刷新选股都拉完整持仓和盘中看板。
