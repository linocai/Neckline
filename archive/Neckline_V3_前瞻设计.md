# Neckline V3 前瞻设计

2026-09-06 · 产品方向稿 · 目标版本 **3.0.0** · **iOS / macOS 均为 Build 31**

V3 已按 K10-v1.4 完成首版实现，并于 2026-09-07 发布 3.0.0 / 双端 Build 31。策略依据为 [K10-v1.4 正式规范](../../whynotme/K10.md)；本稿保留产品目标与范围，工程决策和施工计划由 [PROJECT_PLAN.md](../PROJECT_PLAN.md) 统一管理。

## 产品目标

围绕 K10 重新设计一个消息驱动的创业板纯选股器：帮助用户发现事件、比较公司、选择关注、听取正反分析，并验证推荐后两个交易日的表现。

以新 App 的标准重新设计信息架构、页面、交互、数据模型和运行流程。现有 Neckline 是可复用的基础；每项功能是否保留，以它是否服务 K10 为依据。通过现有项目升级交付，原有导航、成绩包和定时链不构成新设计的限制。

## V3 要提供什么

| 能力 | 产品用途 |
|---|---|
| 发现机会 | 系统先比较公司，明确主推、备选或并列、优先理由、差距和排序改变条件。晚间最多 30 家涉及新机会的不同公司；同股多催化合卡。 |
| 选择与深析 | 用户留下、明确略过或暂不处理。留下后逐票执行正方、反方各一轮；全文、分歧、来源与未完成状态可查看。 |
| 延续关注 | 普通更新延续原机会，不重开窗口、不占新名额；重要反证优先提示。真正的新阶段或独立催化在推荐时说明新增事实和新的两日理由。 |
| 跟进变化 | 晨报先看反证与论点变化，再看继续观察、到期和新增。已略过、未处理的对象也更新；新机会不自动继承旧选择。 |
| 评价效果 | 全部正式候选自动跟踪 D1/D2。以两日内至少一次收盘封板为主指标，冻结留下、略过、未处理三个组，单列重叠机会、停牌、缺数与异常。 |
| 配套服务 | 提供设置、来源覆盖、任务、实际模型用量、通知、离线阅读与个人纪律提醒；iOS/macOS 核心能力一致。 |

这些是能力范围；导航和工程组织以主计划为准，参考图不限定板块数量或页面布局。

## 视觉与交互方向（已确认）

用户已确认 V3 沿用下列参考图的视觉风格，并认可逐张浏览、留下或略过的卡片筛选逻辑。

**功能逻辑与信息呈现第一，视觉第二。** 参考图只确定整体风格，不要求像素级统一；页面组织、组件尺寸、文案和交互应适应真实业务状态、信息密度与平台习惯，不为贴合演示图牺牲可用性。

- **浅色、克制、重阅读：** 白色与微暖白底，深色中文无衬线文字；用标题、正文、时间和标签形成清晰层次。
- **卡片承载内容：** 圆角、细边线、轻阴影和适当留白；事件、公司、正反意见与两日结果各有明确归属。
- **颜色表达用途：** 蓝色用于主操作与选中态，琥珀色提示待核事项；低饱和绿与暖红辅助区分正反观点，状态同时用文字说明。
- **逐卡做选择：** 事件事实复用，公司卡合并同批多条催化；留下、略过、取消关注和找回针对同一公司推荐。留下后进入逐票分析，所有正式候选保留评价记录，未操作始终标为未处理。
- **双端各有所长：** Mac 利用宽屏并排阅读和比较；iPhone 以单列卡片、明确按钮和分层详情完成同一流程。具体导航、手势与尺寸后续细化。

## 一天如何使用

- **晚间 21:00：** 扫描消息，展示公司比较；用户留下、明确略过或暂不处理，留下后阅读正反分析。
- **次晨 09:00：** 补扫隔夜增量。先看重大反证、论点变化、继续观察与到期，再看新增机会与待核事项。
- **两个交易日内：** 按需查看和修改关注，记录真实操作时间；后台自动补齐全部正式候选的两日行情。
- **D2 收盘：** 结束该机会。展示两日结果或具体资料缺口，原窗口不因缺数、未涨或未处理而延长。

统一北京时间。资料截止与实际可查看时间独立：后者决定 D1/D2，晚间与次晨开盘前发布可共享窗口。
开盘时或之后才可查看的推荐标迟到，从下一交易日起观察。两个扫描窗口之间无需常驻资讯采集。

## 必须贯穿的产品原则

- 系统完成公司基础比较，再交用户选择；行情只作为价格反应与验证资料，不生成交易计划。
- 同一旧催化不因转载、每日刷新、改选或股价上涨而变成新机会。重要反证撤回推荐仍保留原两日成绩。
- 全部正式候选跟踪，主推、备选与折叠推荐同口径；关系底稿里的公司不追认为推荐。
- D1 开盘前冻结三个互斥选择组，之后改选留真实时间。多催化共用一次选择，新机会不继承旧机会选择。
- 同公司同首发批次和窗口共用一份成绩；后发重叠机会单列，行情按公司与交易日共享，不能重复计主成绩。
- 主命中率只纳入已到期、两日完整可核的主样本；未到期、停牌、缺数、异常及已知结果都保留。
- 原始判断与来源不可被新版本覆盖。数据补齐修订结果，不能移动窗口或事后改变主样本归属。
- 普通程序负责采集、去重与初筛，模型负责理解与核证；真实覆盖、积压、失败、耗时与成本如实呈现。

## 复用与删除

**按需复用基础能力：** 行情采集与校验、交易日历、模型接入、鉴权、推送、存储与版本记录、备份恢复、双端构建和签名。数据契约与接口按 K10 重新组织；成熟实现经适配验证后复用。

**删除复盘功能：** 交割单导入、FIFO 交易回合、材料装订、复盘结论存档和“我的成绩”整体退出 V3，连同专用后端、接口、设置、测试与存储依赖一并清理。K10 两日选股验证保留；完整交易计划、买卖价位确认和持有退出同步退休。价格观察不视为实际成交。

**退出 K9 生产主线：** V3 围绕 K10 运行。切换完成后清理 P2/P3/P4、旧参数装配、机械核对与结算、旧页面和专用任务；不为沿用旧框架保留无用途的兼容层。实际数据清理在工程阶段确认目标、迁移边界与可恢复备份后执行。
