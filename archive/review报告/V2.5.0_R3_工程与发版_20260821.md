### 🔴-3 · 本版所有 import 型守门（G1–G7 / G18 / G19 / G21）**都能被一行相对 import 绕过**

这是本次复审最要紧的一条。本版大量「结构性保证」压在 AST import 扫描上，而**六份扫描器里有五份显式跳过相对 import**：

`tests/guard_scan.py:36`（以及 `test_v250_s5_params_guard.py:61`、`test_v250_s6_k9_guard.py:44`、`test_v250_s3_facts_guard.py:55`、`test_v250_s4_scorecard_guard.py:50` 各抄了一份）：

```python
elif isinstance(node, ast.ImportFrom) and node.module and not node.level:
```

`not node.level` = **`from ..llm import factory` 这类相对 import 直接不进结果集。**
第六份 `test_v250_s1_retirement_guard.py:84-85` 收了相对 import，但收成 `"..sentinel"`，而 `_hits()` 比的是前缀 `neckline.sentinel` —— **同样对不上，同样零命中**。

实测结果见 §五 反例表 CE1/CE3/CE4/CE5/CE11/CE20/CE21/CE22/CE23 —— **九条全绿（绕过）**，对照组的绝对 import 全部当场红。也就是说：

| 声称「已结构性锁死」的边界 | 一行相对 import 就能破 |
|---|---|
| G2 策略层零 LLM / 零联网 | `neckline/k9/*.py` 加 `from ..llm import factory` |
| G3 取数唯一来源是事实包 | `from ..data import market_data` |
| G4 四通道互不知道 | `p1_breakout.py` 加 `from . import p2_rebound` |
| G5 解释层零 import k9 | `explain/input.py` 加 `from ..k9 import ranking` |
| G7 核对表 / 结算 / 复盘零 LLM | `auction/checklist.py`、`review/conclusions.py` 加 `from ..llm import factory` |
| G19 退役包零残留 | `from ..sentinel import quotes` |
| G21 结算拍零推送 | `auction/settle.py` 加 `from ..push import apns` |

顺带两个同族口子（危害小但同理）：
- **动态 import**：`importlib.import_module("httpx")` 绕过 G2（CE4 实测绿）。
- **字符串拼接**：`importlib.import_module('why'+'notme')` 绕过 G18 的两条判据（CE 实测绿）。

**为什么这条排第一**：本仓目前 106 个 `.py` 里只有 **1 处**相对 import（`neckline/search/__init__.py:3`），所以**今天没有实际违规**。但「已锁死」这句话的价值，全在于下一个人写错时它会红。而相对 import 是 Python 里最自然的包内写法 —— 这道闸恰好对最可能发生的那种写法失明。

**修复方向**（一处改，全部受益）：
1. `tests/guard_scan.py::imports()` 把相对 import **解析成绝对模块名**（拿 `path` 相对 `Backend/` 的位置算出包路径，`node.level` 上溯 N 层再拼 `node.module`），并给它加一条自检：喂一个写着 `from ..llm import factory` 的 bait 文件必须被 `imports_any(bait, "neckline.llm")` 命中。
2. 把 `test_v250_s{1,3,4,5,6}_*.py` 里那五份各自的 `_imports` / `_imported_modules` **全部删掉，改 import `guard_scan`**（`guard_scan.py` 的模块 docstring 自己写着「两份各自漂移的扫描器比一份写错的更糟，所以只留一份」—— 现实是有六份）。
3. 顺带在 `guard_scan` 加一条：`importlib.import_module(<常量字符串>)` / `__import__(<常量>)` 也计入命中。
