# Neckline 4.0.0 Build116（B116）执行记录：MCP 登录页修复

## 1. 根因与修复

- 根因：MCP 网关给所有路由（含 `/login`）加了 `Referrer-Policy: no-referrer`。按 Fetch 规范，非 GET 的导航请求在 no-referrer 下 `Origin` 序列化为 `null`，登录的 Origin 校验（必须等于 `https://nk.linotsai.top`）因此每次都失败。B114 的测试用 TestClient 显式带 Origin，没覆盖到浏览器行为。
- 修复：`/login` 的响应改用 `Referrer-Policy: same-origin`（同站表单正常带 Origin，对外站仍不带来源），其他 MCP 路由仍是 `no-referrer`。Origin、CSRF 令牌、Cookie 三项校验不变。回归测试断言登录页与授权跳转的头。
