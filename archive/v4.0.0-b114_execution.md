## 1. 范围

- **只读 MCP**（`/mcp`，和 API 同一个服务，无状态、JSON 响应）：五个只读工具 `read_brief`（简要提示词）、`get_morning_report`（晨报名单）、`get_document`（原文）、`check_pool`（股票池查询）、`get_stock_overview`（单票技术面概览），对应 [V4 记录 §4.2](v4.0.0_execution.md#42-mcp-服务nb对话-agent-的唯一入口) 的四样内容。

- **单票技术面概览**：池内才取数，池外不外呼、只回「不在 K10 股票池」。收盘后一块用 TuShare（加强版：收盘、涨跌幅、成交额、换手率；近 20 日累计涨跌幅、日均成交额、日均振幅；5/10/20 日均线位置；市值、市盈率、市净率；`moneyflow` 净流入额并注明口径）；盘中一块用麦蕊（报价与一分钟 Pro，聚合成五分钟展示并注明）。每块标来源与数据时间，单块失败只剔除该块并写进缺口；在最新可用晨报里的标出对应条目。
- **只读网页**：`/read/<访问码>` 顶部写明简要提示词与用法；新增单票页 `/read/<访问码>/stock/<代码或简称>`，`?format=json` 给结构化数据。
- **health**：`/api/v4/health` 增加 `mcp`、`tushare`、`mairui` 三个布尔量。
- **依赖**：fastapi 0.115.6 → 0.143.3、starlette 0.41.3 → 1.6.0、pydantic 2.10.6 → 2.13.5、uvicorn 0.34.0 → 0.53.0、PyJWT 2.9.0 → 2.14.0，新增 mcp 2.2.0、python-multipart 0.0.32 及其传递依赖，全部钉在 `requirements.txt`（49 个包）。`release.py` 只装 Neckline 的 wheel（`--no-deps`），依赖另装。
