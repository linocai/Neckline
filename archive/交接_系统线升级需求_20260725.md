# 交接 memo:系统线升级需求(策略线 → 系统线,2026-07-25)

> 来源:策略线会话 2026-07-25 与用户长谈定案。本 memo 只列**系统线要施工的部分**,
> 按优先级排序。策略侧背景与研究计划见 `STRATEGY_LAB.md` §四(同日更新),不复述。
> 背景一句话:用户重定位系统为人机协作——**用户 = 唯一决策人**,系统 = 情报收集 +
> 机械分析 + 纪律执行 + 归因审计;机器不再替用户选股。

## 需求 1:仓位章程变更(高危区——碰纪律章程,建议完工后叫一次 review)

- 现行:单笔 2 万 / ≤5 只 / 敞口 60%(`strategy_versions` 现役 config)。
- 新纪律(用户 2026-07-25 定):总资金 12-13 万分**三仓**,单笔 ~4 万、≤3 只,
  敞口上限相应调整(约满仓)。**-5% 止损、回落止盈 5% 不变。**
- **生效时机:用户清掉现有两笔持仓后才切换,切换动作前需用户确认**(staged,
  不要立即改库)。
- 施工要点:唯一源是 `strategy_versions` 现役版本 config
  (`neckline.strategy.brain.get_active()`),哨兵/台账读库自动跟随;
  PROJECT_PLAN §2.1 章程文本同步改;禁止在任何新文件里抄一份常量。
- **新增熔断纪律(用户 2026-07-25 批准,数字已定)**:连续 3 笔止损 或
  单日亏损 ≥ 4000 元(约总资金 3%)→ 当日停止开新仓、次日只减不加,
  完成一次强制复盘后解锁。系统无法物理阻止下单,以哨兵强提醒 + 客户端
  状态标记 + 日志留痕实现;触发与解锁事件都要落库(归因要用)。
- **仓位分配(用户批准)**:三仓 = 2 仓「短线追击」+ 1 仓「呼吸试验」,
  决策日志打法标签与之对应。

## 需求 2:决策日志(预注册式交易日志,新功能)

- 每笔买入**下单前**必录七项:①为什么买 ②为什么这个入场价 ③目标价
  ④离场价格区间 ⑤论点标签(有限枚举:题材主线 / 情绪周期位 / 资金流向 /
  技术形态 / 消息)⑥证伪条件(出现什么情况说明看错,不到止损线也走)
  ⑦**应对方案**(推演 2-3 种次日走势情景,每种写触发条件与动作:买入/持有/
  减仓/放弃;次日复盘时勾选哪种情形兑现——情景树预注册,来源:用户研习的
  短线战法总结 `/Users/linotsai/Lino/whynotme/总结.md` §六)
  ⑧**打法标签**(有限枚举:短线追击 / 呼吸底仓试验——2026-07-25 用户定向
  双打法并存做 A/B,归因必须按打法分开统计)。
- 时间戳必须先于成交(防事后被结果污染——与研究铁律"预注册先行"同原理);
  挂钩 `positions.py` 台账,平仓后自动关联结果。
- 归因输出:按论点标签统计胜率 / 盈亏比,进 4D 周复盘引擎周报。
- 额外一栏:**挂单未成交追踪**(用户习惯挂低价等回踩;记录未成交票的后续
  走势,检验"逆向选择:专接下坠、错过起飞"假设)。

## 需求 3(低优先,可等策略线漏斗审计出结果后一起定形):盘前情报包

- 主线识别器改定位为**拥挤情报件**(K2 判决:板块层有效但无次日领先性——
  当情报展示,不当选股信号)。
- 板块资金流展示(`moneyflow_dc`,2023-09 起有数;v1 上线日 schema 漂移坑
  已修,落盘必须走 `write_table_day`)。
- 复盘情报字段清单(2026-07-25 补,规格来源同上述战法总结 §五/§八):
  涨幅榜 / 跌幅榜 / 涨停梯队 / 跌停榜 / 大盘量能、最强题材及其核心一二名、
  市值偏好与涨跌幅制度偏好(10/20/30cm 哪类受资金欢迎)、题材持续天数
  (区分 2-3 日持续题材 vs 一日游)。以上全部 EOD 数据可算;竞价/L2 盘口
  无数据,不做。
- 晚间消息面自动检查(战法总结 §5.6):持仓 + 自选票公告扫描(减持/立案/
  暴雷/监管),数据源待查(TuShare 公告接口覆盖与时效);可先以 LLM 联网
  搜索兜底(复用 openai_compat 带搜索调用,注意 read_timeout=90 的坑)。

## 需求 4(随本轮升级一并施工;用户已定:试验仓在升级完成后才开首笔):呼吸战法试验仓台账

- 背景:用户 2026-07-25 定向**双打法并存 A/B**——三仓中两仓跑「短线追击」
  (持有 1-3 日,判错即止损换票),一仓试验「呼吸战法」(板块中军底仓
  1-2 周 + 择机日内 T)。30-50 笔后按决策日志归因裁决胜者扩仓。
- 台账需支持:底仓与 T 仓分离记账、T 次数与费用逐笔落账、「先手」成本优势
  跟踪(当前持仓成本 vs 现价距离)。
- 费用地板:单次 T 规模过小会被 5 元最低佣金吃掉费率(2 万规模双边佣金 +
  卖出印花税 ≈ 20 元 ≈ 0.1%);按实际费用落账,供归因判断 T 是否正贡献。
- 细节等漏斗 v2 定稿 + 用户确认启动后再动工,本条先占位。
