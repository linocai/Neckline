01 — 这次改了什么
六条决定
01
窗口用满
内容不再硬性居中在 900px。macOS 改三区:统一工具栏 / 列表栏 376 固定 / 详情栏自适应。左侧导航栏整个去掉,四个板块进工具栏,设置沉底成右端齿轮。
02
字阶收口
原来散着 9.5 到 34px 十七个字号。收成八档 + 两档数字档,全部走 NKFont 常量,⛔ 视图里不再写裸 .system(size:)。
03
披露折叠
「没看≠没有」「参考、非指令」「⛔ 不是 0 分」这类文案一字不改,收进卡片底部的 ⓘ 披露折叠区,正常态只留一行标记。用户裁定。
04
原始件下沉
NKJSONTable 那类等宽键值表不再摊在主界面,收进「审计视图」入口。主界面只留结论 + 少量关键读数(位置关 / 核心关各四项)。
05
个股是一等对象
篮子列表行下面直接列成员;篮子卡里成员是可展开卡,答的是「这只票为什么能进篮子」:进篮理由 + 位置关 / 核心关判定与读数 + 三个参考件 + K7 标注。
06
弹层退役
macOS 上篮子卡从 700×780 的 .sheet 改成右详情栏。iOS 保留 sheet(手机并排放不下),层级关系一致。

08 — 落地前要先解决的
两处交施工侧决断
这两处 mock 里画了、但现有契约支撑不了。怎么处理由施工 agent 判断 —— 是补上支撑、还是降级成现有契约说得出口的样子,两条路都行,唯一不许的是照原样实现:那会做出一个看起来在工作、其实观察不到任何东西的假成功面。第三条是我会话早期报错的一条 bug,一并撤回留档。
本地存储
「已在券商挂 -5% 条件单」勾选
现在是 @State private var checkedLocally,刷新即丢 —— 用户当面提的第一个反人类点。mock 里画了勾选时间戳 +「本机记录,换机不同步」。落地需要按 positionId 存 UserDefaults(⛔ 别写进服务端:它记的是「我在券商那边做了什么」,不是系统能核实的事实)。
需新增端点
批算进度(报告未生成时)
dataFreshness 挂在报告快照上,没报告就没这个字段 —— 此刻 ⑤ 只能显示「本次连数据新鲜度都没查到」。想显示「16:05 批算跑到哪了」,得加一个不依赖报告快照的批算状态端点。状态屏里那条流水线是排程表(读 timer 的固定时刻),不是实时状态,别把它实现成进度条。
已核实无需处理
拼接串里的 Markdown
我在会话早期报过一条「界面上会显示裸 **」的 bug,那是我看错了,撤回。
规则本身成立:SwiftUI 只对字面量 Text 解析 Markdown,+ 拼接出来的 String 走另一个重载、不解析。但全仓扫过,带 ** 的 Text 无一例外都是字面量(PositionsView 合并敞口那句、ReviewView 选股钟那句、DataFreshnessBanner「可能是**没看**而不是**今天真没有**」、BasketScoreCard「(**不是表现好**)」等),现在就是粗体渲染,正确。
而唯一那处拼接串(ReviewView::CalibrationSegmentCard)已经带着注释刻意不放 ** —— 那条坑记在 ReviewView.swift,不在 SharedUI。
⛔ 新增文案时守住这条:拼接串里别放 ** 或反引号。⛔ 也别把现有字面量改成 Text 拼接 + .fontWeight(.bold) —— 那才会把粗体弄没。
