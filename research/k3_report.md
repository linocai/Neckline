## 0. 方法与共同设定(承阶段 1 §0 / k2_report §0)

### 0.1 两条度量跑道(与阶段 1 / K2 完全一致,保证可比)

1. **信号级事件研究**(`neckline.research.eventstudy`):向量化,测「信号本身」的前瞻
   收益期望。执行/成本对齐 Broker——决策日 T 用 T 的 EOD 特征,**T+1 开盘买、
   T+(1+d) 开盘卖**,只统计 `fwd_buyable`(次日有成交且非涨停),净收益 = 毛 −
   2×单边成本(`DEFAULT_COST_ONESIDE=0.0015`,双边 30bp)。B1 主用此跑道。
2. **组合级回测**(`MomentumStrategy`+引擎,带 T+1/涨跌停/停牌/滑点 + 仓位纪律 +
   路径依赖退出):B2 起用,对手 K1。

### 0.2 样本切分 / 纪律设定(防过拟合 + K1 严格可比)

- **样本内(定参)** 2020-01-01 ~ 2024-12-31;**样本外(验证)** 2025-01-01 ~
  **2026-07-17**(`SAMPLE_OUT_END`,**与 K1/K2 冻结口径逐字一致、严格可比**——
  总管 2026-07-24 拍板:主判决窗口**不动**,`SAMPLE_OUT_END` 常量语义不改)。
- **另附「延至最新」补充统计**(2025-01-01 ~ **2026-07-24**,最新交易日):只作
  幸存定义的稳健性旁证,用显式参数传入、**不改共享常量**;末 5 交易日的长持有前瞻
  天然截断(数据止于 07-24),补充窗只看短持有(hold≤2)。
- **纪律设定**(全研究同设定,纪律章程 §2.1):初始 12 万 / 单笔 ≤2 万 / ≤5 只 /
  敞口 ≤60% / T+1 / **-5% 止损** / hold≤5 / 真实费用 + 保守滑点。
- `moneyflow_dc` 仅 2023-09-11 起 → 资金面研究(B3.1)另建同窗基线,不与全期混比。

### 0.3 ★ 均值口径测不到左尾(K3 方法论要害,写死)

事件研究的**均值期望看不到「接刀」的灾难左尾**(stage1 明记)。K3 判「会弹 vs 是刀」
**不只看 fwd 均值**——每个定义同时报**分布**:胜率 + **左尾分位 p5 / p10**(净收益的
第 5 / 10 百分位,越负=尾越肥)+ **跌停暴露**(次日 T+1 跌停占比 `ld_next` /
前 3 持有日任一跌停占比 `ld_hold3`)+ **深亏占比**(hold3 净收益 ≤ -10% 的事件占比)。
**均值尚可但左尾肥的定义 = 刀,不作幸存。**

### 0.4 证据强度三级标注(每条结论必标)

- **个股价格信号 强/中**:K3 主用纯价格量能特征(ret/dist/ma/vol_ratio/consec),
  **无 K2 的 `ths_member` 成分洞**——这是 K3 相对 K2 的干净处。
- **资金面 中(短窗)**:`moneyflow_dc` 2023-09+ 样本有限(B3.1 首测)。
- **前向验证补强**:未来实盘积累。

## B0 · 数据修缮(快修级)

### B0.1 修 `moneyflow_dc` 历史分区 TuShare 类型漂移

**病灶**(k2_report §0.3 记载,阻断 B3.1 资金面纳入):12 个数值列(`pct_change`/
`close`/`net_amount`/`net_amount_rate`/`buy_{elg,lg,md,sm}_amount(_rate)`)在部分历史
分区落成 `String`,与主体 `Float64` 冲突,`pl.scan_parquet` 整表读取直接
`SchemaError: data type mismatch for column pct_change: incoming Float64 != target String`。

实测坏分区分两类(全表 1587 文件,坏 **900** 个):
- ① **2020-2023 早期 897 个 0 行空文件**(空列→pandas object→polars String);
- ② **2026-07-20/21/22 三个含真数据的分区**(共 ~17,671 行)被写成 String——这三天
  正是 daily_update 落盘时 `_align_to_table_schema` 依赖的整表 scan **已被①毒化**、取不到
  干净 target schema,遂退化原样落 String(v1 上线首日毒化 Parquet 的同类现象)。

**修法**(`scripts/fix_moneyflow_schema.py`,承 v1 `_align_to_table_schema` 思路但**显式
canonical=Float64**,不依赖整表 scan 取 target——整表 scan 本身就是坏的、会连带失败):
逐分区文件读入 → 12 列 `cast(Float64, strict=False)`(空串/非法值→null)→ 原地重写。**幂等**。

**验证(修复前 → 修复后)**:

| 项 | 修复前 | 修复后 |
|---|---|---|
| `scan_table_range(moneyflow_dc, 2023-09-11, 2026-07-22)` | **SchemaError**(pct_change Float64≠String) | ✅ 可读 |
| 全窗整表 scan 行数(2020~2026-07-24) | 无法读 | **4,001,434 行** |
| 全 1587 分区 `pct_change` dtype 集合 | {String, Float64} 混杂 | **{Float64} 唯一** |
| 真数据日 2026-07-22 `net_amount` 峰值 | (String)318584.68 | 318584.68(对拍备份**逐位相等**) |
| 2023-09-11 首个真数据日 | 无法读 | 5,412 行,net_amount ∈ [-58427.6, 65226.4] 万元(量级合理) |

**mock 单测**(`tests/test_fix_moneyflow_schema.py`,6 例,先补后动手):合成漂移目录
(空 String 分区 + Float64 canonical + 含真数据的 String 毒源 + 空串/非法值行),验证
① 修前整表 scan 必 SchemaError、② 修后可读、③ 真数据值精确保留、④ 空串/非法值→null、
⑤ 非目标列与列顺序不动、⑥ 幂等 + dry-run 不落盘。**施工中真发现一个陷阱**:
`scan_parquet(...).select(pl.len())` 因投影下推**不读漂移列、不触发 schema 对账**,测不出
漂移;真实 `scan_table_range` 是全列 collect 才炸——helper 已改为投影一个漂移列强制对账。

**副产品**:修后 `_align_to_table_schema` 的整表 scan 恢复(取得干净 Float64 target),
后续 daily_update 的类型漂移会被自动 cast 回 Float64——**B0.2 增量的 07-23/07-24 两天
moneyflow_dc 落盘即为 Float64**,证明防线已恢复。

## ⏸ B1 用户检查点摘要(一页 · 呈用户校准盘感)★

> runner `research/k3_b1_eventstudy.py`(读 K3 扩展面板 `_cache/k3_panel.parquet`),
> 预注册全定义 × 六年事件研究,冻结样本外 = 2025-01-01~2026-07-17。**未获用户放行不进 B2。**

**⚠ 最反直觉的三个发现(需用户实盘盘感裁断):**

1. **★ 趋势背景闸门方向反了(直接挑战中心假设的四道闸设计)。** 施工图设想
   「上升趋势回撤 = 会弹、下降趋势下跌 = 接刀应剔除」。**数据把这条完全说反**:
   设想会弹的**急跌×升势回撤**(C1,站上升年线后急跌)样本外 **-0.77%**、PF 0.756、
   左尾最肥之一(`ld_hold3` 7.5%、深亏 8.6%);设想是刀的**急跌×降势下跌**(C2,
   跌破降年线后再跌)反而 **+0.87%**、PF 1.478、**左尾全场最干净**(`ld_hold3` 3.2%、
   深亏 3.3%)。5 日锚同向(C3 升势 -0.29% vs C4 降势 **+0.88%**/PF 1.518)。
   **经济含义**:真正的刀是「跌破上升年线的强势票」(动量反转/派发,越跌越有人止损),
   会弹的是「已跌透、在下降年线下继续超卖」的弱势票(capitulation 均值回归)。
   **若照施工图把「下降趋势下跌」当刀剔除,恰好扔掉唯一正期望的一档、留下真刀。**
   趋势背景**确实把会弹与接刀分开了**(★校验通过)——只是分水岭的正负号与假设相反。

2. **缩量才是刀,判据是量能不是阴跌天数。** 跌法维度:**缩量**(`vol_ratio_5≤0.8`)
   无论急跌缓跌都是最肥左尾——B3 缩量急跌样本外 -1.01%、`ld_hold3` **13.1%**、深亏
   **10.7%**(全场最差);放量(B1/B5)左尾干净(`ld_hold3` 3-5%)。「放量急跌更会弹、
   缩量是刀」的预注册假设**被证实**,但真正判据是**量能**(放/缩),不是「阴跌天数」。

3. **2026 是超卖买入的通杀刀年——均值回归 edge 高度 regime 依赖(K2 非平稳同病)。**
   **所有**超跌定义(不分深度/跌法/趋势)逐年一致:2024/2025 正(PF 1.2–2.9)、

4. **全体超跌 edge 高度 regime 依赖(2024-25 正 / 2026 通杀)**,与 K2 非平稳同病——
