## 0. 方法与共同设定(承阶段 1 §0 / k2_report §0)

### 0.1 两条度量跑道(与阶段 1 / K2 完全一致,保证可比)

1. **信号级事件研究**(`neckline.research.eventstudy`):向量化,测「信号本身」的前瞻
   收益期望。执行/成本对齐 Broker——决策日 T 用 T 的 EOD 特征,**T+1 开盘买、
   T+(1+d) 开盘卖**,只统计 `fwd_buyable`(次日有成交且非涨停),净收益 = 毛 −
   2×单边成本(`DEFAULT_COST_ONESIDE=0.0015`,双边 30bp)。B1 主用此跑道。
2. **组合级回测**(`MomentumStrategy`+引擎,带 T+1/涨跌停/停牌/滑点 + 仓位纪律 +
   路径依赖退出):B2 起用,对手 K1。

### 0.2 样本切分 / 纪律设定(防过拟合 + K1 严格可比)

- **样本内(定参)** 2020-01-01 ~ 2024-12-31;**样本外(验证)** 2025-01-01 ~
  **2026-07-17**(`SAMPLE_OUT_END`,**与 K1/K2 冻结口径逐字一致、严格可比**——
  总管 2026-07-24 拍板:主判决窗口**不动**,`SAMPLE_OUT_END` 常量语义不改)。
- **另附「延至最新」补充统计**(2025-01-01 ~ **2026-07-24**,最新交易日):只作
  幸存定义的稳健性旁证,用显式参数传入、**不改共享常量**;末 5 交易日的长持有前瞻
  天然截断(数据止于 07-24),补充窗只看短持有(hold≤2)。
- **纪律设定**(全研究同设定,纪律章程 §2.1):初始 12 万 / 单笔 ≤2 万 / ≤5 只 /
  敞口 ≤60% / T+1 / **-5% 止损** / hold≤5 / 真实费用 + 保守滑点。
- `moneyflow_dc` 仅 2023-09-11 起 → 资金面研究(B3.1)另建同窗基线,不与全期混比。

### 0.3 ★ 均值口径测不到左尾(K3 方法论要害,写死)

事件研究的**均值期望看不到「接刀」的灾难左尾**(stage1 明记)。K3 判「会弹 vs 是刀」
**不只看 fwd 均值**——每个定义同时报**分布**:胜率 + **左尾分位 p5 / p10**(净收益的
第 5 / 10 百分位,越负=尾越肥)+ **跌停暴露**(次日 T+1 跌停占比 `ld_next` /
前 3 持有日任一跌停占比 `ld_hold3`)+ **深亏占比**(hold3 净收益 ≤ -10% 的事件占比)。
**均值尚可但左尾肥的定义 = 刀,不作幸存。**

### 0.4 证据强度三级标注(每条结论必标)

- **个股价格信号 强/中**:K3 主用纯价格量能特征(ret/dist/ma/vol_ratio/consec),
  **无 K2 的 `ths_member` 成分洞**——这是 K3 相对 K2 的干净处。
- **资金面 中(短窗)**:`moneyflow_dc` 2023-09+ 样本有限(B3.1 首测)。
- **前向验证补强**:未来实盘积累。

## B0 · 数据修缮(快修级)

### B0.1 修 `moneyflow_dc` 历史分区 TuShare 类型漂移

**病灶**(k2_report §0.3 记载,阻断 B3.1 资金面纳入):12 个数值列(`pct_change`/
`close`/`net_amount`/`net_amount_rate`/`buy_{elg,lg,md,sm}_amount(_rate)`)在部分历史
分区落成 `String`,与主体 `Float64` 冲突,`pl.scan_parquet` 整表读取直接
`SchemaError: data type mismatch for column pct_change: incoming Float64 != target String`。

实测坏分区分两类(全表 1587 文件,坏 **900** 个):
- ① **2020-2023 早期 897 个 0 行空文件**(空列→pandas object→polars String);
- ② **2026-07-20/21/22 三个含真数据的分区**(共 ~17,671 行)被写成 String——这三天
  正是 daily_update 落盘时 `_align_to_table_schema` 依赖的整表 scan **已被①毒化**、取不到
  干净 target schema,遂退化原样落 String(v1 上线首日毒化 Parquet 的同类现象)。

**修法**(`scripts/fix_moneyflow_schema.py`,承 v1 `_align_to_table_schema` 思路但**显式
canonical=Float64**,不依赖整表 scan 取 target——整表 scan 本身就是坏的、会连带失败):
逐分区文件读入 → 12 列 `cast(Float64, strict=False)`(空串/非法值→null)→ 原地重写。**幂等**。

**验证(修复前 → 修复后)**:

| 项 | 修复前 | 修复后 |
|---|---|---|
| `scan_table_range(moneyflow_dc, 2023-09-11, 2026-07-22)` | **SchemaError**(pct_change Float64≠String) | ✅ 可读 |
| 全窗整表 scan 行数(2020~2026-07-24) | 无法读 | **4,001,434 行** |
| 全 1587 分区 `pct_change` dtype 集合 | {String, Float64} 混杂 | **{Float64} 唯一** |
| 真数据日 2026-07-22 `net_amount` 峰值 | (String)318584.68 | 318584.68(对拍备份**逐位相等**) |
| 2023-09-11 首个真数据日 | 无法读 | 5,412 行,net_amount ∈ [-58427.6, 65226.4] 万元(量级合理) |

**mock 单测**(`tests/test_fix_moneyflow_schema.py`,6 例,先补后动手):合成漂移目录
(空 String 分区 + Float64 canonical + 含真数据的 String 毒源 + 空串/非法值行),验证
① 修前整表 scan 必 SchemaError、② 修后可读、③ 真数据值精确保留、④ 空串/非法值→null、
⑤ 非目标列与列顺序不动、⑥ 幂等 + dry-run 不落盘。**施工中真发现一个陷阱**:
`scan_parquet(...).select(pl.len())` 因投影下推**不读漂移列、不触发 schema 对账**,测不出
漂移;真实 `scan_table_range` 是全列 collect 才炸——helper 已改为投影一个漂移列强制对账。

**副产品**:修后 `_align_to_table_schema` 的整表 scan 恢复(取得干净 Float64 target),
后续 daily_update 的类型漂移会被自动 cast 回 Float64——**B0.2 增量的 07-23/07-24 两天
moneyflow_dc 落盘即为 Float64**,证明防线已恢复。

### B1.0 预注册:研究面板扩展(载体缺口前置)

K3 扩展面板 = 现研究面板 + 以下新特征(**只进 K3 研究面板**,落 `research/_cache/
k3_panel.parquet`,不改生产报告读的既有列语义;全部后向窗口、无前视):

| 新特征 | 口径 |
|---|---|
| `ma60` / `ma250` | `close.rolling_mean(60/250, min_samples=60/250).over(ts_code)`(半年线/年线) |
| `ma250_slope_up` | `ma250 > ma250.shift(20)`(年线上升,趋势背景判据) |
| `ma60_slope_up` | `ma60 > ma60.shift(10)`(半年线上升,中间态细分) |
| `dist_from_ma250` | `close/ma250 - 1`(距年线) |
| `dist_from_ma60` | `close/ma60 - 1`(距半年线) |
| `consec_down_days` | 连续 `ret_1d<0` 天数(run-length,阴跌判据) |
| `ret_5d_pct` / `ret_10d_pct` | 当日横截面涨跌幅分位(0~1,承 `add_ret_rank_column` 姿势,低分位=当日跌得最狠一档) |
| `fwd_ld_next` / `fwd_ld_hold3` | T+1 是否跌停 / T+1~T+3 任一跌停(跌停暴露度量,`is_limit_down` 前向 shift) |

> **⚠ ma250 硬数据下限(诚实标注)**:本地 daily 仅 2020-01-02 起、**无 2019 数据**,
> `ma250`(需 250 交易日预热)在样本最早约 1 年(2020 全年 ~ 2021-01 初)为 **null**,
> `ma250_slope_up`(再退 20 日)更晚。故**趋势背景维度(③)的有效窗口 ≈ 2021-01 起
> (~5.5 年)**,非全 6 年;深度/跌法/位置维度(用 ret_1d/5d/10d/20d/dist_from_high_20d
> 等短窗特征)为**全 6 年**。趋势背景定义在 2020 年因 ma250=null 自然剔除(无前视代价,
> 只是样本少一年)——这是数据边界、非设计选择,结论解读时须记此差异。

### B1.1 预注册定义清单(五维度 × 粗网格,在 K3 base 域之上叠加)

**K3 base 域(常开,所有超跌定义共叠加 = 质量过滤 ④):**
```
k3_base = base_universe_expr()                 # 非ST/非BSE/close≥2/amount_ma20≥2000万/ma20非空
          & (board == "MAIN")                   # 主板 only(排除 GEM/STAR 高弹;-5% 对20%涨跌幅过紧,承 stage1 P6)
          & (days_since_listing >= 120)          # 非次新
```
> 质量过滤是「与接刀的第一道区分」,常开不作被研究参数。**主板 only** 兼答 stage1 P6
> (高弹题材 -5% 止损相对其波动过紧被噪声反复扫);超跌票波动更大,主板更保 -5% 有效。

**① 跌幅深度(depth,单维度触发器,各跑 6 年事件研究):**

| id | 名称 | 定义(叠加 k3_base) |
|---|---|---|
| A1 | 单日急跌5 | `ret_1d ≤ -0.05` |
| A2 | 单日急跌7 | `ret_1d ≤ -0.07` |
| A3 | 5日回落10 | `ret_5d ≤ -0.10` |
| A4 | 5日深跌15 | `ret_5d ≤ -0.15` |
| A5 | 10日深跌15 | `ret_10d ≤ -0.15` |
| A6 | 20日深跌20 | `ret_20d ≤ -0.20` |
| A9 | 5日跌横截面底5% | `ret_5d_pct ≤ 0.05` |
| A10 | 5日跌横截面底10% | `ret_5d_pct ≤ 0.10` |

**⑤ 位置(position,承 stage1 P5 逆——被禁的「距前高远」那批 PF 全场最高):**

| id | 名称 | 定义 |
|---|---|---|
| A7 | 距20高-15 | `dist_from_high_20d ≤ -0.15` |
| A8 | 距20高-20 | `dist_from_high_20d ≤ -0.20` |
| A11 | 距年线-15 | `dist_from_ma250 ≤ -0.15`(需 ma250,~5.5 年窗) |

**② 跌的方式(manner,放量急跌 vs 缩量阴跌;锚在深度触发器上):**

| id | 名称 | 定义 | 假设 |
|---|---|---|---|
| B1 | 放量急跌1.5 | `ret_1d ≤ -0.05 & vol_ratio_5 ≥ 1.5` | 恐慌抛售/放量见底 → **更会弹** |
| B2 | 放量急跌2.0 | `ret_1d ≤ -0.05 & vol_ratio_5 ≥ 2.0` | 同上,更极端 |
| B3 | 缩量急跌 | `ret_1d ≤ -0.05 & vol_ratio_5 ≤ 0.8` | 无量急跌(对照) |
| B4 | 缩量阴跌 | `consec_down_days ≥ 3 & ret_5d ≤ -0.08 & vol_ratio_5 ≤ 0.8` | 无恐慌、阴跌不止 → **接刀嫌疑高** |
| B5 | 放量5日跌 | `ret_5d ≤ -0.10 & vol_ratio_5 ≥ 1.5` | 放量中期回落 |

**③ 趋势背景(★反弹 vs 接刀分水岭,~5.5 年窗;锚在深度触发器 A1/A3 上):**

| id | 名称 | 定义 | 角色 |
|---|---|---|---|
| C1 | 急跌×升势回撤 | `A1 & close>ma250 & ma250_slope_up` | **反弹候选**(站上年线+年线升) |
| C2 | 急跌×降势下跌 | `A1 & close<ma250 & ~ma250_slope_up` | **接刀候选,应被剔除** |
| C3 | 5日跌×升势回撤 | `A3 & close>ma250 & ma250_slope_up` | 反弹候选 |
| C4 | 5日跌×降势下跌 | `A3 & close<ma250 & ~ma250_slope_up` | 接刀候选 |
| C5 | 急跌×中间态 | `A1 & close>ma250 & ~ma250_slope_up`(站上年线但年线未升) | 中间态(ma60 细分) |

> **★ 核心校验(B1.4 地图)**:C1 vs C2、C3 vs C4——趋势背景是否真把「上升趋势回撤」
> (会弹:正期望 + 左尾可控)与「下降趋势下跌」(是刀:负期望或左尾灾难)**分开**。
> **分不开 = 中心假设的区分站不住 = 等同中心假设被否**(施工图明写)。

**④/交叉:全地图(depth × trend_context):** A1/A3 两锚 × {升势回撤 / 降势下跌 /
中间态 / 全域(不分趋势)} 的 fwd 期望 + 左尾矩阵(B1.4 呈)。

### B1.2 度量口径(每定义)

- 事件数 `n`(buyable)、hold=1/2/3/5 的:胜率 `win`、净均值 `mean_net`、净中位 `median_net`、
  盈利因子 `PF`、**左尾 `p5_net`/`p10_net`**、**跌停暴露 `ld_next`/`ld_hold3`**、**深亏占比**
  (hold3 净 ≤ -10%)。净收益扣双边成本 0.0015×2。
- **分层**:年份 / 市场状态(`sse_above_ma`)/ 趋势背景(C 类的 up-vs-down 即核心分层)。
- **敏感性 ±1 格**:A1(-0.04/-0.05/-0.06/-0.07)、A3(-0.08/-0.10/-0.12/-0.15)、
  B1 vol_ratio(1.3/1.5/2.0)、A7(-0.10/-0.15/-0.20)——防悬崖最优。

### B1.3 幸存判据(预注册,先于结果)

一个定义**入 B2 幸存候选**须同时:① hold∈{1,2,3} 至少一档**净均值 > 0 且 PF > 1**
(样本内外**同向**,不要求样本外也正但不得反号灾难);② **左尾可控**——`p5_net`
不比同锚全域基线显著更肥、`ld_hold3` 不显著抬升、深亏占比可控;③ 事件数足量(样本外
n ≥ 100,避免偶然)。**只报告倾向,最终幸存 2–3 名交用户检查点校准后由 B2 定。**
