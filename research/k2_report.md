## 0. 方法与共同设定(承阶段 1 §0)

### 0.1 两条度量跑道(与阶段 1 完全一致,保证可比)

| 跑道 | 工具 | 用途 |
|---|---|---|
| 信号级事件研究 | `neckline.research.eventstudy` | 测「信号本身」前瞻收益期望(每笔等权,net 扣双边 ~30bp) |
| 组合级回测 | `MomentumStrategy`+`BacktestEngine` | 带 T+1 / 涨跌停 / 停牌 / 滑点手续费 + 仓位纪律 + 路径依赖退出 |

### 0.2 样本切分 / 纪律设定

- 样本内(定参)2020-01-01~2024-12-31;样本外(验证,有限次)2025-01-01~2026-07-17。
- 回测纪律(§2.1,全程固定不研究):初始 12 万 / 单笔 2 万 / ≤5 只 / 敞口 ≤60% /
  T+1 / **-5% 止损** / hold≤5,**全读现役 K1 config,不硬编**。
- K1 现役 config 实测:`strength=none` / `buypoint=pullback` / `stop_pct=0.05` /
  `take_profit_retrace=0.05` / `max_hold_days=5` / `single_cap=20000` / `max_positions=5` /
  `max_exposure_frac=0.6` / `forbid_high_elasticity=True`。

`adj_factor`/`moneyflow_dc` 补 07-20/21/22(07-18/19 周末非交易日);概念板块
`ths_index`/`ths_daily`/`ths_member` 经 `backfill_concept.py --force`(END=20260722)重拉——
`ths_daily` 2020-01-02~2026-07-22(499,373 行,394 概念),`ths_member` 当前快照(71,650 行)。
**仅本地、走阿里云镜像、concept 拉取守 450/分限频、未碰 ECS**;落盘一律走既有脚本

2020~2026-07-17(样本外窗口口径固定、可复现),07-22 校准另建单日切片(见 B2.5)。
